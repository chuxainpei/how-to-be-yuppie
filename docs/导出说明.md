# 导出说明

Markdown 是唯一源文件；PDF 由同一批文件生成，不单独修改 PDF。

## 环境

- Python 3.10+，`pip install weasyprint markdown`
- 字体：Noto Sans CJK SC、Noto Serif CJK SC（Regular 与 Bold，OTF），可从 [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk) 下载。放在任意目录，用环境变量 `BOOK_FONT_DIR` 指向它（默认 `/workspace/work/fonts`）。

## 命令

```bash
python3 tools/book.py nav     # 按 data/topics.tsv 顺序刷新每篇文末“上一课／回目录／下一课”
python3 tools/book.py merge   # 合并 data/fragments/ → data/prices.tsv、sources.tsv、terms.tsv
python3 tools/book.py tables  # 由数据表生成 book/ 下的术语表、费用样本表、来源记录、奥莱品牌目录、同店同餐比价记录
python3 tools/book.py check   # 内链、文件存在、TSV 列数、ID 唯一、价格引用的 source_id 是否存在
python3 tools/book.py pdf     # 生成 dist/精致大学生的第0课.pdf（并留下 dist/book.html 便于排查）
python3 tools/book.py all     # 依次执行以上全部
```

## PDF 的处理规则

- A4，页边距约 19—20 mm，正文 Noto Serif CJK SC 10.8 pt、行距 1.65；标题、表格、引用块用 Noto Sans CJK SC。字体完整嵌入。
- 封面 → 目录（含页码，可点击）→ 前言 → 八个章节 → 附录。每个章节和每篇文章另起一页。
- 书签：章节为一级、文章为二级、文章内 H2 为三级。
- 页眉左侧显示当前文章标题，右侧为书名与版本；页脚居中页码。
- 文内相对链接转为 PDF 内跳转；外链保持可点击。GitHub 折叠块 `<details>` 在 PDF 中展开显示。
- 表头跨页重复；表格行、引用块尽量不被分页切断；长网址允许断行。
- 文末导航行只在 Markdown 中显示，PDF 中省略。

## 修改一篇文章后

1. 改 `book/` 下的正文；涉及价格或来源时改 `data/fragments/` 对应行和 `docs/核验记录/<ID>.md`。
2. 运行 `python3 tools/book.py all`，确认 `check` 输出 `0 issue(s)`。
3. 在 `CHANGELOG.md` 记一行。
