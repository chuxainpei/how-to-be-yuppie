# 编写规范（第四版，2026-10-21）

第四版取代第三版。看完 v0.3.0 后定下的方向：

- 这些文章要放到作者个人网站（pkusi.com）的文章汇总里，**读者看到的每个字都是给读者的**，不能有任何仓库、许可、数据、版本之类的内部字样。
- 现在的文风像“老油条”：不表态、不担责。要**贴标签、敢表态**。作者的责任是把想法传给后来的人，不用怕担责任。
- 这是**经验分享，不是报告**。大量数据和严谨语气要去掉，**人情味是重点**。
- 目录有很多重复场景，重新整理（已整理为 25 篇、四部分，见 `data/topics.tsv`）。

## 1. 声音：一个过来人学长，坐在宿舍里跟学弟学妹聊

- **先下结论，再讲为什么。** 每篇开头第一段就把我的立场亮出来，像标题一样硬：“洗牙每年一次，第一次就去，别等。”
- **贴标签。** 敢说“这是智商税”“这一步必须做”“这种店别进”“贵有贵的道理”“这钱花得值”。给读者一个能记住的判断，而不是一串“视情况而定”。拿不准的地方也给倾向：“如果非要我选，我选 A。”
- **人情味。** 承认第一次去的紧张、怕被宰、怕露怯、怕店员的眼神，把这些说出来，然后告诉他没关系、该怎么办。语气像朋友，可以调侃，可以心疼，可以护短：“你是来花钱的，不用怕任何人。”
- **讲经验，不讲数据。** 价格只留读者做决定真正需要的一两个，用口语说（“七八百一位”“一副好镜片三五百就够”）。一篇最多一张账单图。日期、机构名、收费编码、注册证编号、精确到分的金额、视频时间戳，统统删掉，除非它就是那个让人记住的点。
- **少一点严谨腔。** 删“通常”“一般来说”“可能”“建议咨询专业人士”式的反复免责。医疗类保留一句真正有用的底线就够（比如“眼睛红痛畏光，当天就去医院”），说得斩钉截铁。
- **比喻和场景**：食堂、宿舍、快递、外卖、考试、社团、校园卡。一篇一两个，落得准。
- **结尾**：停在一句像学长临走前拍拍肩膀的话，具体、可执行，不升华。

## 2. 诚实的底线（只有一条）

可以写普遍经验和判断：“第一次去的人十个有八个会……”“很多人卡在门口那一下”。**不要写具体编造的个人故事**（“我大二那年在三里屯……”“那天店员对我说……”），因为读者会把它当真事。表态可以很狠，事实不能是编的；正文写到的价格、规则如果和原稿不同，以原稿资料为准。

## 3. 绝对不能出现在正文和图里的字样

商标/许可说明（“图标仅作识别用途”“商标归各品牌所有”“CC BY”“不在许可范围”）、仓库路径（`assets/`、`data/`、README）、来源编号（SRC-xxx）、版本号（v0.x）、研究腔（核验、待核、样本、口径、本轮、抓取、检索、适用范围），以及 AI 式自我交代：“我无法确认，所以一个数字都没写”“名词不熟”“这里我没查到”“以下内容仅供参考”。没查到的东西，**直接不写**，或者告诉读者到了现场问哪一句。

图片上不放来源、日期、备注小字（`figs.py` 已不渲染 `note`），卡片里也不要写“编辑整理”之类。

## 4. 去 AI 味（沿用第三版第 2 节清单）

二分否定“不是X而是Y”全文最多一次；不升华收尾；不宏大开场；不用首先/其次/值得注意的是；不强行三段式；不写人造金句；不堆“打造、赋能、氛围感、高级感”；不滥用破折号和粗体；不写“本文将介绍”。别矫枉过正：不硬塞“说实话”“绝了”。

## 5. 版式

- H1 与 `data/topics.tsv` 的 `title` 逐字一致，标题本身就是标签：`# 洗牙：别怕，每年去一次`。
- 不写元信息行，不写编号，小标题用有态度的短句（“门口那一下最难”）。
- 正文表格 0 张为佳，最多 1 张。图 0—2 张，只画真正需要一眼看全的东西（一张账单、一个流程、一个分叉）。图名用 `<topic_id>-<短名>`，如 `figures/13-账单.yaml`。
- 可照读的话用引用块，每篇 2—4 句，口语。
- 文末 `## 参考`：3—8 条对读者有用的链接（官网、医院科普、官方规则），格式 `- [标题](url)`，不写编号、不写日期。
- 文末保留导航占位 `<!-- NAV -->`（工具生成）。
- 篇幅 1500—3000 字；合并篇可到 3500 字。宁短勿水。

## 6. 资料与记录

原稿事实、价格、来源都在旧文章（`work/r3/` 备份与 git 历史）、`docs/核验记录/<旧ID>.md`、`data/` 里，写作时当素材库用，**不搬进正文**。每篇新写一份 `docs/核验记录/<新topic_id>.md`：合并自哪些旧篇、删掉了哪些数据、保留的价格各出自哪条来源。数据表不删行。
