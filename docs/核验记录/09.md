# 09 痘痘：三个月不见好，就去皮肤科

- 正文：book/1-把自己收拾体面/痘痘.md；图：figures/09-该不该去.yaml → assets/figures/09-该不该去.png
- 合并自：S02、S03（旧稿备份 work/r4src/S02-*.md、S03-*.md；旧核验记录 docs/核验记录/S02.md、S03.md）
- 核心立场：轻度痘先洗对脸、管住手，给三个月；不见好或出现结节、留疤、情绪受影响等情况就去皮肤科，别自己挤、别乱买祛痘产品和疗程。
- 说明：“三个月”是第四轮按用户指定立场设定的时间点；旧稿依据为 AAD“粉刺治疗给 6—8 周”及指南“外用药至少 6—8 周评估”，正文写作“外用药至少给它一两个月再判断”，不冲突。
