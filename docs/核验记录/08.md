# 08 护肤：洗脸、保湿、防晒，三样就够

- 正文：book/1-把自己收拾体面/护肤.md；图：figures/08-账单.yaml → assets/figures/08-账单.png
- 合并自：S01（旧稿备份 work/r4src/S01-我怎样建立简单可坚持的护肤.md；旧核验记录 docs/核验记录/S01.md）
- 核心立场：日常护肤只要洁面、保湿、防晒三样，防晒最值得花钱；精华、面膜、爽肤水、“药妆”宣称多半是智商税。
