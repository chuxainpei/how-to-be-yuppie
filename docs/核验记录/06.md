# 06 隐形眼镜：日抛最省心，OK镜多半不是给你的

- 正文：book/1-把自己收拾体面/隐形眼镜.md；图：figures/06-怎么选.yaml
- 合并自：E02（第一次戴隐形眼镜）+ E03（是否适合角膜塑形镜）。旧核验记录见 E02.md、E03.md。
- 立场按任务要求：日抛最省心；OK 镜主要用户是青少年（控制近视进展），大学生多数不值。“诊室里多半是中小学生”属普遍经验判断，未引具体统计。

## 删掉的数据
- 各品牌日抛/月抛的活动价与日期（视康 53.31、舒日 198/109.05、欧舒适 166.53、奥澈 264/44.49）及月度账算式与旧图。
- 上海/圣康华角膜曲率、验光、角膜地形图、眼轴收费；深圳 4—14 小时逐日戴镜表；注册证查询路径细节。
- OK 镜：角膜曲率 39—48 D、内皮细胞 2000/mm²、完整适应证/禁忌证清单、验配流程全列、复查时间节点、护理用品清单、1—1.5 年换片原文；宁夏人民医院中标价 3000/3400/3500/3900 元/片、16 省联盟集采价；两张旧图（验配流程、异常信号）。

## 保留的价格及出处
- “检查费几十块”：E02 引 SRC-E-009（上海角膜曲率 12 元/单侧 + 显然验光 13 元，双眼 37 元）、SRC-E-012。
- “30 片日抛只够双眼 15 天；天天戴一个月一两百，偶尔戴几十块”：E02 月度账（视康天天戴 106.62 元、舒日 218.10—396 元、舒日只周末戴 105.60 元，来源 SRC-E-021/023）。“几十块”指更少天数的情形，按同一单价推算。
- “医院买 OK 镜片就要三千块左右一片，你付的只会更多”：E03 引 SRC-E-031（宁夏回族自治区人民医院中标价常规片 3000 元/片起）。
- 停戴 OK 镜 3 个月以上才能做激光手术：SRC-E-003。第一天戴约 4 小时：SRC-E-030。
