# 品牌标志文件说明

本目录存放 B01、B02 品牌识别表使用的标志图片，共 32 个文件，对应 `data/brand-identifiers.tsv` 中 33 个品牌里的 32 个（New Balance 未取得合格图形，正文用文字占位）。每个文件的来源页面、原始资源地址、取得日期和状态都记在那张表里。

## 商标归属与使用边界

- 这些标志是各品牌权利人的注册商标或商业标识，**所有权归各自权利人**。
- 本项目引用它们只为一件事：让读者在店招、吊牌和官网上认出品牌（识别用途）。引用不表示品牌赞助、授权、合作或认可本书。
- **这些文件不属于本项目的 CC BY 许可范围。** 转载、改编或再分发本书时，如果要连同这些标志一起使用，需要自行判断所在地区的商标与版权规则，必要时向权利人取得许可；不想承担这一判断时，删掉本目录，正文表格会退化成文字。
- 官方网站或媒体资源页面能公开看到某个标志，不等于权利人允许任何人再分发它。开云集团 logo library 是面向媒体的资源页，页面上没有看到面向公众的再分发许可。
- Wikimedia Commons 上标为“公有领域”或 CC0 的标志文件，这类标注只处理版权（多数理由是“简单文字或几何图形不构成作品”），**不解除商标权**。

## 取图规则

1. 优先级：品牌或集团官方媒体资源（`official_asset`）→ 品牌或集团官网页面中直接使用的字标（`official_page_extract`）→ Wikimedia Commons 上注明取自品牌官网的文件（`secondary_commons`）→ 取不到就文字占位（`missing_text_placeholder`）。
2. 不使用 AI 生成、手绘、凭记忆重绘的图形，也不从来源不明的 PNG 聚合站下载。来源注明为 brandsoftheworld 等聚合站的 Commons 文件同样不用。
3. 允许的处理只有：裁去空白、缩放到高 80 像素、把白色单色字标改为黑色以便白底显示、从官方组合图中裁出单个品牌。凡做过处理的，`trademark_note` 列都写明了。没有改动任何图形的形状、比例和文字。
4. 花纹（Monogram、GG、格纹、编织）、五金、技术标识不当作 logo 收录；它们在正文里用文字说明。
